# Dead Reckoning

Sean's writing roadmap as a phone app: this week's sessions (track + step), Book 1 / proposal / memoir step trackers (Track A), blog post pipeline (Track B), the year's phases and deadlines, and the agent hunt.

- Progress saves on the device. Optional sync to a private GitHub repo (More tab).
- Install: open the GitHub Pages link in Safari, Share, Add to Home Screen.
- Dates match `writing-plan-v2-for-specter.ics`.
